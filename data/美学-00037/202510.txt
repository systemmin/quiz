#一、单项选择题：1.美学思想属于（B）A.感性认识B.理性认识C.非理性认识D.不自觉的认识
-理性认识
感性认识：是通过感官直接获得，比如看到景色、听到音乐，是直观、表面的感觉、知觉、表象。
理性认识：是对事物本质、规律的概括，形式包含概念、判断、理论、思想。2.黑格尔认为美学的研究对象是（B）A.美的规律B.艺术C.审美经验D.审美关系/ 黑格尔美学研究艺术
3.影响主体审美趣味的主要因素是（A）A.社会条件B.生理特征C.先天禀赋D.个性才能
-审美趣味本质上受社会文化、时代、阶级、教育等社会条件制约，这是最主要因素
/ 审美趣味主要由社会条件决定4.审美活动本身所展开的是一个（B）A.情感的世界B.属人的世界C.生命的世界D.物质的世界
-审美活动只发生在人与对象之间，只有人才能进行审美。审美活动打开的不是单纯情绪、生命或者物质世界，而是属人的世界（为人所体验、人所建构的意义世界）。
/ 审美活动展开属人的世界5.在审美活动中，审美主体看重的是（A）A.对象的精神意义B.对象的形式创新C.对象的物质功利性D.对象的实际用途
-审美活动的特点：非功利性，不关注事物实际用途、物质功利。
/ 审美超越物质功利，追求精神意义。6.最基本、最普遍的形式规律是（B）A.均衡对称B.多样统一C.节奏韵律D.对比调和
-多样统一（也叫和谐）是形式美的最基本、最普遍的总规律，其他都是它的具体表现形态。其他项都属于多样统一下面的具体形式法则
/ 形式美总规律 = 多样统一7.审美形态是对人类审美实践活动中的审美经验的（D）A.诗意表达B.感性表达C.抽象演绎D.逻辑总结
-审美形态（优美、崇高、悲剧、喜剧、丑和荒诞），是理论家对大量审美经验进行归纳、提炼，形成的理性、逻辑层面的概括总结。
/ 审美形态 = 对审美经验的逻辑总结
8.优美感的心理特征表现在对象与主体之间的（B）A.服从B.和谐C.斗争D.对立
-优美的核心：主体和对象之间没有冲突、压迫，呈现和谐统一，心理感受轻松愉悦。
/ 优美 = 和谐；崇高 = 对立斗争9.认为崇高和优美都是“活的形象”的美学家是（A）A.席勒B.康德C.黑格尔D.克罗齐
-黑格尔提出美是理念的感性显现，美是活的形象，并且认为崇高和优美都属于 “活的形象”。
席勒：提出游戏说、审美教育。
康德：对崇高和优美做区分，没有 “活的形象” 这个表述。
克罗齐：直觉说，美即直觉。
/ 黑格尔 —— 活的形象10.人们面对崇高最终体验到的是一种（B）A.渺小感和压迫感B.力量感和实现感C.无奈感和恐惧感D.臣服感和满足感
-崇高的审美过程：首先面对巨大对象，产生恐惧、渺小感；随即唤起人的精神力量去战胜这种压迫，最终获得力量感与自我实现感。
- 力量感和实现感、无奈感和恐惧感：只是崇高审美初期的感受，不是最终体验。
- 臣服感和满足感：臣服感错误，崇高不是臣服对象，而是精神超越。
/ 崇高先压抑，最终获得力量感、实现感11.在西方美学史上真正奠基了悲剧理论基础的是（B）A.德谟克利特B.亚里士多德C.苏格拉底D.柏拉图
-亚里士多德《诗学》系统探讨悲剧，提出悲剧的定义、情节、卡塔西斯（净化）理论，奠定西方悲剧理论的基础。德谟克利特：原子论，美学上侧重摹仿说，但没有系统悲剧理论。
苏格拉底：关注美和善的统一。
柏拉图：贬低悲剧，认为悲剧滋养人的情欲。
/ 亚里士多德《诗学》奠基悲剧理论

其他项都是积极正面的人性特质，和荒诞内涵相反。
/ 荒诞 = 人的异化与生存局限
13.夏夫兹博里提出的美学主张是（C）A.表现说B.迷狂说C.内在感官说D.心理距离说-夏夫兹博里（夏夫兹伯里）提出内在感官说，认为人除了眼耳等外在感官，还有一种天生的 “内在感官”，用来直接感知美。

心理距离说：布洛
/ 夏夫兹博里 — 内在感官说
14.杜威的美学思想属于（A）A.实用主义B.存在主义C.解释学D.唯意志论
-杜威是实用主义哲学代表，美学代表作《艺术即经验》，核心观点：艺术来源于日常经验，审美就是完整经验。
存在主义：萨特等
解释学：伽达默尔
唯意志论：叔本华、尼采
/ 杜威 = 实用主义美学，艺术即经验15.提出“智者乐水，仁者乐山”这一主张的是（C）A.老子B.庄子C.孔子D.孟子
-出自《论语・雍也》：知（智）者乐水，仁者乐山。
老子：道家，主张大音希声、大象无形。
庄子：逍遥游、心斋坐忘。
孟子：性善论、充实之为美。
/ 智者乐水，仁者乐山 — 孔子

16.北岛的诗句“卑鄙是卑鄙者的通行证，高尚是高尚者的墓志铭”运用的是（C）A.接近联想B.类似联想C.对比联想D.回忆联想
-对比联想：由事物对立的特点引发联想。诗句将 “卑鄙” 和 “高尚” 对立对照，形成强烈反差，属于对比联想。
接近联想：时空上邻近的事物（看到落日想到黄昏）。
类似联想：相似特征的事物（莲花想到君子）。
回忆联想：不是美学联想分类里的标准术语。
/ 对立反差 → 对比联想17.移情论美学认为审美经验产生于主体对客体的（A）A.情感投射B.情感共鸣C.理性思考D.理性沉思
-移情说（立普斯）核心：审美时人把自己的情感投射到对象身上，仿佛对象本身也有情感（比如山在欢呼、树在哀愁）
/ 移情说 = 主体情感投射到客体18.中国古代诗学认为诗无达诂，这说明审美理解具有（C）A.直观性B.抽象性C.多义性D.模糊性

-“盖身即山川而取之” 出自郭熙《林泉高致》，意思是画家要亲身置身山川之中，依靠身体的直观体验去感受山水，再进行创作，强调审美经验离不开身体的亲历，与身体相关。

-缘情说（陆机《文赋》“诗缘情而绮靡”）：文学是抒发人的情感。

22.与对象在感性形态上具有相似性的意象类型是（D）A.抽象B.喻象C.兴象D.仿象
- 仿象：主体模仿客观对象的感性形态创造意象，意象和对象外形相似。
抽象：舍弃具象外形，提炼形式符号，不相似。
喻象：以物喻情，重在比喻象征，外形不一定相似。
兴象：由外物触发情感，情景交融，重在兴发，不强调外形相似。
/ 仿象 = 模仿对象感性形态，外形相似23.“玄之又玄，众妙之门”，这句话可以用来描述艺术作品中的（B）A.意象B.意境C.形式D.技巧
-“玄之又玄，众妙之门” 出自《道德经》，形容幽深玄妙、难以言传的境界。意境是情景交融、虚实相生，具有无限韵味的审美境界，玄妙含蓄，契合这句话的内涵。

形式、技巧：都属于外在载体，不是玄妙的境界本身。
/ 玄之又玄 → 意境
