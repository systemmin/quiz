#一、单项选择题：
1.美学研究的中心问题和主要对象是（C）
A.美和美的本质
B.审美经验
C.人和世界之间的审美关系
D.审美心理
-美学研究的中心问题、主要对象，是人与世界的审美关系：
研究对象：人与世界的审美关系
传统美学核心探讨问题：美的本质

2.审美活动实质上是主体与客体之间的一种（C）
A.反映的关系
B.静态的关系
C.动态的关系
D.抽象的关系
-审美活动不是静态的认识，而是主体（人）和客体（审美对象）相互作用、交融的动态活动：
/ 审美活动是主体与客体之间动态的审美关系。

3.将人的需要区分为生存需要、享受需要和发展需要三个层次的是（B）
A.恩格斯
B.马克思
C.马斯洛
D.黑格尔
-马克思把人的需要划分为三个层次：生存需要、享受需要、发展需要。
恩格斯：和马克思共同创立理论，但该三层划分是马克思；
马斯洛：需要层次理论是 5 层：生理、安全、归属与爱、尊重、自我实现；
黑格尔：德国古典唯心主义哲学家，没有这套需要划分。
/ 马克思：生存、享受、发展；马斯洛：五层需要

4.在主体审美心理结构中必然处于最高位置的是（B）
A.审美需要
B.审美理想
C.审美经验
D.审美趣味
-审美理想在主体审美心理结构里居于最高位置，是主体心中完善的美的观念，统帅审美趣味、审美需要、审美经验：
审美需要：是审美活动的内在驱动力，属于基础；
审美经验：是过往审美活动积累下来的体验；
审美趣味：是个人审美偏好、喜爱倾向，受审美理想引导。
/ 审美理想 → 最高；审美需要 → 动力；审美趣味 → 偏好；审美经验 → 过往体验。

5.审美活动之所以吸引人、感染人，是因为它所展开的是一个（D）
A.情感的世界
B.意象的世界
C.美妙的世界
D.属人的世界
-审美活动打开的是属人的世界。审美活动让人摆脱单纯物质功利，建立起人独有的意义世界，这正是它吸引人、感染人的根本原因。
情感的世界：情感是审美重要要素，但不是审美活动展开的世界本质；
意象的世界：意象是审美对象的形态；
美妙的世界：只是通俗描述，不是美学理论表述。
/ 审美活动建构一个属人的世界，是人独有的生存体验。

6.就目前的研究来看，在原始社会中促进审美发生最重要的中介因素是（D）
A.种族繁衍活动
B.生产劳动
C.游戏活动
D.巫术礼仪活动
-原始社会审美发生最重要的中介是巫术礼仪活动。
种族繁衍：是原始人类重要活动，但不是审美发生核心中介；
生产劳动：是审美发生的根本前提，但不是中介因素；
游戏活动：游戏说只是审美起源学说之一，不是最重要中介；
/ 根本前提：生产劳动；最重要中介：巫术礼仪

7.能够使人的本质力量得到最充分的显露的是（C）
A.认识活动
B.创造活动
C.审美活动
D.宗教活动
-审美活动能够使人的本质力量得到最充分的显现。
认识活动：侧重把握客观规律，有限度展现人的本质力量；
创造活动（实践劳动）：可以展现人的本质力量，但会受到功利目的束缚；
宗教活动：本质是人的本质力量的异化。
/ “审美活动是人的本质力量最充分的显露”，人在审美中摆脱功利束缚，自由直观自身。

9.古希腊人乃至整个西方最主要的思维方式是（C）

B.象数思维

形象思维：艺术创作常用；
象数思维：中国传统（周易）；
直觉思维：非理性直观，不是西方主流。
/ 西方→抽象逻辑思维；中国古代→象数思维。

B.荒诞感的心理特征

荒诞感：人与世界分裂、不协调；
悲剧感：存在矛盾冲突，经历痛感之后升华；
喜剧感：以矛盾、反差、不合逻辑为基础。
/ 优美 = 主客体和谐；悲剧、喜剧、荒诞都存在冲突。

康德：《判断力批判》，从主体判断力分析美。
/ 托马斯・阿奎那：完整、和谐、鲜明

21.用一些纯粹的形式符号来唤起读者审美情感的意象属于（D）
A.兴象
B.喻象
C.仿象
D.抽象
- 抽象：以纯粹形式符号唤起审美情感，不摹仿具体物象，比如几何图案、抽象绘画。
兴象：中国古典美学，自然景物触发情感，情景交融（如唐诗）。
喻象：以物象做比喻，寄托主体情思（如梅兰竹菊）。
仿象：模仿客观现实物象，再现事物外形
/ 仿象 = 模仿物象；喻象 = 比喻寄托；兴象 = 感兴自然（触景生情，情由景起）；抽象 = 纯粹形式符号

时空综合艺术：戏剧、舞蹈、电影
/ 空间艺术：绘画、雕塑、建筑

23.从意象的类型上看，左拉、福楼拜、莫泊桑的小说中的意象属于（C）
A.兴象
B.喻象
C.仿象
D.抽象
-仿象：主体模仿客观世界的物象，再现现实事物形态，追求逼真再现。左拉、福楼拜、莫泊桑属于现实主义作家，小说着重摹写现实生活，意象以模仿现实为主，属于仿象。
兴象：中国古典美学，外物感发情感，情景自然交融（唐诗）
喻象：借物象比喻寄托主观情思（梅兰竹菊）
抽象：纯粹形式符号，不摹仿具体物象
/ 现实主义作品 → 仿象

24.艺术符号对其意义的表达只能通过的方法是（D）
A.暗喻与拟人
B.比喻与象征
C.夸张与变形
D.象征与暗示
-艺术符号和普通语言符号不一样，不能直接明说含义，只能依靠象征、暗示来传达意义。
暗喻、拟人：属于修辞手法，不是艺术符号表达意义的根本方式
比喻：是直接打比方，艺术符号不只是比喻
夸张、变形：是塑造形象的手法，不是表达意义的方式
/ 艺术符号对于意义的表达，只能通过“象征与暗示”

想象：加工表象，构建形象
理解：理性思考
/ 黑格尔 → 情感凝聚意象的核心

#三、简答题：
36.简述美学思想与审美意识的关系。
审美意识是感性、零散的审美体验，是美学思想产生的基础；美学思想是对审美意识的理性概括与理论升华。美学思想源于审美意识，又反过来指导审美意识。

37.简述审美活动作为价值活动的特殊性。
①审美活动追求的不是实用功利价值，而是精神价值；
②审美价值只能通过对象的感性形式呈现；
③审美价值不是预先存在的，是在主客体交融的审美活动中生成；
④审美价值指向人的生命体验与终极关怀，促进人性完善。

38.简述审美惊异的主要特征。
①审美惊异不是求知的好奇心，而是感性直观的审美体验；
②摆脱日常功利，中止实用态度；
③具有突发性、非预期性；
④实现主客体之间瞬间的交融。
/ 非好奇，脱功利，突发感，主客融

39.简述夏夫兹博里的“内在感官说”。
①夏夫兹博里提出内在感官说，认为人除外在五官外，还有心灵的内在感官（第六感官）。
②内在感官天生具备，能够直接辨别美丑善恶，美感与道德感相通。
③它拥有感官的直接性，但根植于人的理性心灵，区别于动物的感官。
④该理论把审美能力归于人先天的心灵能力，由哈奇生进一步发展。
/ 夏夫兹博里首创，哈奇生继承；内在感官 = 理性 + 直接感知，美善相通。

40.简述审美情感与一般情感的差异。
①功利性不同：一般情感源于现实利害；审美情感超越功利。
②产生方式不同：一般情感来自现实刺激；审美情感由感性形象、想象唤起。
③范围不同：一般情感偏重个体；审美情感具有普遍可传达性。
④性质不同：一般情感混杂本能欲望；审美情感是净化升华、情理统一的情感。
/ 去功利，靠形象，可共鸣，情净化

41.简述美育的目的。
①美育培养人的审美能力，包括感受美、鉴赏美、创造美的能力；
②根本目的是塑造完整人性，弥合感性与理性的分裂；
③陶冶人的情感，净化心灵，提升精神境界；
④促进人的全面发展，实现人的精神自由。
/ 练审美，全人性，净心灵，促发展

#四、论述题：
42.试论喜剧的基本特征。
①喜剧的基本审美效果是笑，这是审美性的笑，不是单纯生理反应；
②喜剧对象存在内在矛盾，以虚假外观掩盖空虚本质（黑格尔）；
③喜剧带有理性批判，通过嘲笑揭露虚伪、荒谬的事物；
④欣赏喜剧时主体获得精神优越感与自由感；
⑤喜剧具有社会历史性，讽刺对象随时代变迁。
/ 喜剧通过揭示事物内在矛盾引发审美之笑，在愉悦的审美体验中批判现实，使人获得精神解放与思想反思。

#五、分析说明题：
43.以《西游记》中的孙悟空形象为例，说明艺术意象的基本特征。
艺术意象是审美想象中构造、饱含情感的感性形象，基本特征如下：
①虚拟性：意象并非现实实存。孙悟空是石猴成神，七十二变等神通都是虚构，现实不存在，但扎根现实生活体验。
②感性：意象具备可感的外在形态。孙悟空毛脸、金箍棒、筋斗云，以具体形象呈现，可供直观感受。
③想象性：意象依靠想象创造与接受。作者融合猴、人、神的特点，通过想象塑造；读者也要通过想象在脑中还原形象。
④情感性：意象凝聚情感。作者借孙悟空寄托反抗压迫、追求自由的情感；读者也会产生喜爱、敬佩等情感共鸣。
